# 기획서 작성 프로그램

Streamlit으로 실행하는 기획서·결과보고서 작성 도구입니다. Python **3.12**를 사용하세요.

## GitHub → Streamlit 배포

1. ZIP을 압축 해제합니다.
2. 새 GitHub 저장소에 `proposal-writer` **폴더 안의 파일과 하위 폴더 전체**를 올립니다. 저장소 최상단에 `app.py`, `requirements.txt`, `templates`, `assets`가 있어야 합니다. `.streamlit/config.toml`도 포함하세요.
3. Streamlit Community Cloud에서 저장소와 브랜치를 선택하고 Main file path를 `app.py`로 설정합니다.
4. Advanced settings에서 **Python 3.12**를 직접 선택하고 배포합니다. `.python-version`만으로 Cloud의 Python 버전이 바뀐다고 가정하지 마세요.
5. Google API, Apps Script, 서비스 계정 및 Secrets 설정은 필요하지 않습니다.

## 로컬 실행

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Windows에서는 가상환경 활성화 명령으로 `.venv\Scripts\activate`를 사용합니다.

## 사용 순서

- **기본 정보**: 기획서/결과보고서 양식, 프로그램명, 행사명, 날짜와 선택적인 시간을 입력합니다.
- **참석자·장소**: 드롭다운에서 선택합니다. 목록에 없으면 이름이나 장소를 직접 입력한 뒤 Enter로 추가합니다. 참석 대상은 개인 또는 그룹 모두 가능합니다.
- **내용·예산**: 기획서는 추진 목적, 주요 진행 내용, 기대 효과와 예산을 작성합니다. 결과보고서는 주요내용을 작성합니다. 예산 합계는 자동 계산합니다.
- **사진**: 파일을 선택하고 ‘선택한 사진 추가’를 누릅니다. 설명 입력, 순서 변경, 삭제가 가능합니다.
- **확인·출력**: ‘PDF·Word 파일 준비’를 누른 후 원하는 파일을 다운로드합니다. PDF는 인쇄용, Word는 추가 편집용입니다.

‘상용구 관리’에서 자주 쓰는 문구를 등록·검색·수정·삭제할 수 있습니다. 본문에서도 바로 상용구를 저장하거나 불러와 뒤에 추가/교체할 수 있습니다. ‘보관 문서’에서 지난 문서를 복사하거나, 첫 단계에서 필요한 항목만 선택해 재사용할 수 있습니다.

## 저장 방식 — 꼭 읽어 주세요

Google Sheets 및 별도 데이터베이스를 사용하지 않습니다. 입력 문서, 사진, 상용구는 **현재 접속 세션의 서버 메모리**에만 있습니다. 브라우저 새로고침·종료, 연결 해제 또는 서버 재시작 시 사라질 수 있습니다. 접속자 간 자료도 자동 공유되지 않습니다.

작업 종료 전 **백업·복원 → 백업 파일 준비 → ZIP 다운로드**를 하세요. 다음 접속 때 해당 ZIP을 복원하면 초안, 보관 문서, 사진과 상용구를 이어서 사용할 수 있습니다. 복원은 현재 세션 자료 전체를 교체합니다. PDF/Word 파일을 앱으로 다시 불러오는 기능은 없습니다.

내용을 수정한 후에는 백업 파일을 다시 준비해야 최신 내용이 반영됩니다. 백업은 50MB 이하, 보관 문서는 100건, 상용구는 500개까지 지원합니다. 이 앱은 파일을 Google에 전송하지 않지만, 업로드된 사진과 입력 내용은 앱 실행 서버에서 처리됩니다.

## 사진과 출력 양식

- JPG, PNG, WebP 지원. 사진 한 장당 10MB 이하·4천만 화소 이하, 문서당 최대 10장.
- HEIC는 JPG나 PNG로 변환해서 올려 주세요.
- 세로/가로 비율을 유지합니다. EXIF 방향을 반영하고, 긴 변 2,000픽셀로 축소하여 JPEG로 저장합니다. 투명 영역은 흰색으로 바뀌며 원본 메타데이터는 제거됩니다.
- 기획서의 사진은 ‘첨부사진’, 결과보고서는 ‘행사사진’ 아래에 들어갑니다. 내용이 길거나 사진이 많으면 다음 페이지로 넘어갑니다.
- 첨부된 기획서·결과보고서 Word 양식의 A4 용지, 제목, 항목 순서, 여백과 예산 표를 바탕으로 구성했습니다. Word는 실제 DOCX 템플릿을 채우고 PDF는 같은 구조로 생성합니다.
- 배포 환경에서 한글을 안정적으로 출력하기 위해 원본 바탕체 대신 **나눔명조**를 사용합니다. PDF는 글꼴을 내장합니다. Word를 열 PC에 나눔명조가 없으면 `assets/fonts`의 글꼴을 설치해 주세요. PDF와 Word의 줄바꿈·페이지 수는 편집 프로그램에 따라 조금 다를 수 있습니다.
- 일반 한글과 영문 중심 문서용입니다. 이모지나 특수 문자는 글꼴 지원에 따라 표시되지 않을 수 있습니다.

## 기본 명단 변경

`settings.json`을 수정하세요. 실제 개인 정보는 공개 GitHub 저장소에 올리지 않는 편이 좋습니다.

```json
{
  "people": ["참석자 A", "참석자 B"],
  "places": ["세미나실", "회의실", "온라인"]
}
```

Secrets는 기본 명단 설정에 사용하지 않습니다. 새로 입력한 이름은 현재 초안/보관 문서와 백업에 함께 들어갑니다.

## 선택 사항: 접속 비밀번호

배포된 앱에 간단한 공통 비밀번호를 적용하려면 Streamlit의 Secrets에 다음을 설정하세요. 로컬에서는 `.streamlit/secrets.toml`에 저장할 수 있으며, 이 파일은 GitHub에 올리지 마세요.

```toml
app_password = "원하는-긴-비밀번호"
```

이 기능은 간단한 접속 제한이며 사용자별 계정이나 권한 관리는 제공하지 않습니다.

## 구성과 확인

- `app.py`: 입력 단계, 상용구, 문서 보관 및 다운로드 UI
- `model.py`: 문서 데이터, 사진 처리, 백업·복원 검증
- `exports.py`: PDF/Word 생성
- `templates/`: 출력용 Word 템플릿 (파일명과 `{{...}}` 표시를 유지하세요)
- `assets/fonts/`: 한글 글꼴과 OFL 라이선스
- `tests/`: 출력, 이미지, 백업, 입력 흐름 테스트

```bash
pip install pytest pypdf
python -m pytest tests -q
```

`requirements.txt`의 버전 조합을 유지하세요. 사진·출력 기능에는 별도 운영체제 패키지나 Google 인증이 필요하지 않습니다.
